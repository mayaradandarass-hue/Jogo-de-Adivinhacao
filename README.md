# 🎮 Jogo de Adivinhação

Um jogo interativo de adivinhação implementado em **C** e **Python**, onde o jogador tenta adivinhar um número secreto dentro de um intervalo escolhido.

---

## 📋 Funcionalidades Comuns

- 🎮 Escola de intervalo personalizado para o número secreto
- 📊 Três números de dificuldade:
  - **Fácil:** 15 tentativas
  - **Médio:** 10 tentativas
  - **Difícil:** 5 tentativas
- 🔥 Sistema de feedback com emojis (🔥 quente, ✨ muito quente, ❄️ frio)
- 💯 Sistema de pontuação dinâmico (começa com 1000 pontos)
- 🎨 Arte ASCII decorativa
- 🔄 Operação de jogar múltiplas rodadas
- ✅ Validação robusta de entrada

---

## 🔧 Versão em C (Adivinhação.c)

**Vantagens:**
- ⚡ Execução mais rápida
- 💾 Menor consumo de memória
- 🖥️ Mais próximo do hardware

**Como Compilar e Executar:**
```bater
gcc -o Adivinhação Adivinhação.c
./Adivinhação
```

---

## 🐍 Versão em Python (Adivinhação.py)

**Vantagens:**
- 📖 Código mais legal e fácil de manter
- 🚀 Desenvolvimento mais rápido
- ✅ Sem necessidade de compilação

**Como Executar:**
```bater
python3 Adivinhação.py
```

## 🎯 Como Jogar

1. Executar o programa (C ou Python)
2. Escola o intervalo de números (ex: 1 a 100)
3. Seleção do nível de dificuldade
4. Venha a Adivinhar!
5. Receba feedback sobre se está no chão de acertar o número
6. Perda pontos se errar ou conservar pontos se acertar

Boa sorte! 🍀
